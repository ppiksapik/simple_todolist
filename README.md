## ✨ Fitur Utama
- [x] **Tambah Tugas:** Menambahkan daftar pekerjaan baru.
- [x] **Lihat Daftar:** Menampilkan seluruh tugas yang tersimpan di database.
- [x] **Ubah Status / Edit:** Menandai tugas yang sudah selesai atau memperbarui teks tugas.
- [x] **Hapus Tugas:** Menghapus tugas yang tidak lagi diperlukan.

---

## 🛠️ Teknologi yang Digunakan
* **Backend:** Node.js, Express.js
* **Frontend:** EJS (Embedded JavaScript), CSS3
* **Database:** SQL (MySQL / PostgreSQL)
